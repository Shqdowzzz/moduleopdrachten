Diag JS1 Oefentoets - vlaggen

Opdracht 0

  • Kopieer de HTML en CSS van deze pagina (rechtermuisknop -> "view page source") en zet hem op je eigen computer.
  • zet de css in een apart bestand en link die naar de html file.
    Wis de opdrachten divs en gbruik het verder voor opbouw van jouw eigen oefentoets.

Opdracht 1

  • Zorg ervoor dat als je op de bovenste kleur klikt, deze rood wordt.
  • Maak een button "kleuren veranderen" die met de gegeven JS variabelen, alle kleuren van de vlag verandert.
  • Maak 3 input type="text" vakken, waarin je de (css) kleurnaam kan typen en die met een onKeyUp event die kleur de vlag kunnen veranderen.

Opdracht 2

Er staan ook andere vlag-kleuren gedeclareerd in de JS variabelen.
  • Maak 3 buttons met landnamen (NL, BE, DE) die de kleuren van de vlag veranderen.
  • Zorg dat de naam van het land dynamisch in een div onder de vlag komen te staan.
  • maak een for-loop van 0 tot 2 en zorg dat het land in elke kleur van de vlag komt te staan.
  • in de map "img" staan deze afbeeldingen van de vlaggen: vlag_bulgarije.png, vlag_hongarije.png, vlag_duitsland.png, vlag_nederland.png, vlag_belgie.png.
    gebruik deze om de vlag te maken.
  • Zet de gegevens in een array zoals hieronder let vlaggegevens = [ [ "NL", "red", "white", "blue" ], [ "BE", "black", "yellow", "red" ], [ "DE", "black", "red", "gold" ] ]; Gebruik deze array in een for-loop om de kleuren van de vlag te veranderen.
  • Maak een loop door de array heen en zorg dat er 3 vlaggen komen te staan.

  • Maak een array met de username en password combinaties van de gebruikers. en test die
  • Zorg ervoor dat de inlogformulier met een animatie verdwijnt uit beeld als het inloggen gelukt is. Niet gelukt? Laat het formulier staan en voeg dynamisch, een rode error message toe onder de button.
